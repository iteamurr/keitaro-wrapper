## Живой Keitaro

Для записи создана отдельная тестовая кампания. После проверки она отключена.
Существующие кампании и глобальный объект использованного оффера не изменялись.

- Чтение справочников, поиск оффера, импорт и Fetch прошли.
- Создание вернуло кампанию с regular-геопотоком и default-потоком офферов.
  Сохранены страна, HTTP-редирект, ID справочников и параметры источника.
  Итоговая ссылка построена из подтверждённых домена и alias.
- Локальное закрепление доли не изменило Keitaro; Cancel восстановил черновик.
- Удаление привязки снаружи отразилось в архиве после Fetch.
  Bring Back и реальный Push восстановили привязку с долей 100%.
- PUT только с `offers` заменил состав; остальные настройки сохранились,
  кроме нормализации пустого `action_payload` из `null` в `""`.
  Gateway учитывает её только для схемы `landings`; добавлены регрессионные тесты.
- Повтор Create и Push с прежним ключом вернул исходный результат.
- Устаревшая ревизия и удаление последнего активного оффера отклонены.
- Внешнее изменение потока остановило Push с конфликтом; черновик сохранился.

## Границы проверки

У тестовой учётной записи нет права создавать офферы: API отвечает 403.
Поэтому живая проверка использовала один существующий оффер. Перераспределение
между несколькими офферами проверено доменными, интеграционными и браузерными тестами
с синтетическим каталогом.

Фактический переход посетителя по географическому маршруту не проверялся:
проверена сохранённая конфигурация потоков. Обрыв соединения с живым Keitaro
после записи не имитировался; восстановление таких операций проверено на стенде.
Атомарная условная запись внешнего API не подтверждена — между чтением
и PUT остаётся окно для внешнего изменения.

Подробный контракт и статус K-01–K-05: [спецификация интеграции](../specs/001-keitaro-contract.md).
